This guide helps you bootstrap a Beztack project locally.

## Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) 22 (the version CI runs)
- [pnpm](https://pnpm.io/) 11
- [PostgreSQL](https://www.postgresql.org/) with an empty database
- [Git](https://git-scm.com/)

## Create a New Project

You can create a new Beztack project using the `create-beztack` command:

```bash
pnpm create beztack
```

The CLI will walk you through:

- **Project name**: The name for your new project (lowercase with dashes)
- **Project description**: A short description of your project
- **Default currency and locale**: An ISO 4217 code (for example `USD`) and a BCP 47 tag (for example `en-US`), written to the `.env.example` files. Beztack has no built-in default and the apps refuse to start without them.
- **Initialize Git repo?**: Choose if you want to set up a new Git repository
- **Install dependencies?**: Choose if you want to automatically install dependencies using `pnpm install`
- **Modules**: Optional modules (payments, email, AI, OCR, state management) and, when payments is selected, the payment provider

The CLI copies this repository into your new folder. Its closing "Next steps"
message prints `pnpm run push`, which is not a script in the project. Use the
database commands below instead.

## Initial Setup

Once the project is created, navigate to the directory and set up your environment:

### 1. Set Up Environment Variables

Copy the `.env.example` file of each app to `.env`:

```bash
cd your-project
cp apps/api/.env.example apps/api/.env
cp apps/ui/.env.example apps/ui/.env
cp apps/docs/.env.example apps/docs/.env
```

### 2. Configure Required Variables

Open the `.env` files in each app directory and set the required variables.
At minimum, configure the database, `BETTER_AUTH_SECRET`, `APP_NAME`,
`DEFAULT_CURRENCY`, `DEFAULT_LOCALE`, the Resend settings, and the credentials
of the payment provider you plan to use (Polar or Mercado Pago, selected with
`PAYMENT_PROVIDER`).

### 3. Initialize the Database

Apply the migrations:

```bash
pnpm db:migrate
```

To sync the schema without migration files during early development, use `pnpm db:push`.

## Development

Start all services in parallel:

```bash
pnpm dev
```

This will start:

- **UI** at http://localhost:5173
- **API** at http://localhost:3000
- **Docs** at http://localhost:3002

### Running Individual Apps

Beztack uses Nx for task execution. You can run individual apps:

- **UI:** `nx dev ui`
- **API:** `nx dev api`
- **Docs:** `nx dev docs`

### Production Build

To build all projects:

```bash
pnpm build
```

Or build specific projects:

```bash
nx build ui
nx build api
```
